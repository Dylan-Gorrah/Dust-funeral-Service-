# Images Directory

Place your images here:

## Required Images

1. **hero-bg.jpg** (1920x1080px minimum)
   - Peaceful landscape or sunset
   - Used in the hero section
   - High quality, professional

2. **logo.png** or **logo.svg** (200-300px wide)
   - Your company logo
   - Transparent background preferred
   - Used in navigation and footer

3. **favicon.ico** (optional)
   - Small icon for browser tab
   - 32x32px or 64x64px

## Image Optimization Tips

- Use JPG for photos
- Use PNG for logos with transparency
- Use SVG for vector graphics
- Keep file sizes under 500KB
- Use next/image component (already implemented)

## Where Images Are Used

- `components/Hero.tsx` - Background image
- `components/Navigation.tsx` - Logo
- `components/Footer.tsx` - Logo
- `components/WhyChooseUs.tsx` - Feature images (optional)
- `components/Locations.tsx` - Map (can use Google Maps embed instead)
